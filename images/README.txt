IMAGES FOLDER — PHOTO NAMING GUIDE
====================================

Put all your photos in this folder (birthday-website/images/).
Use EXACTLY these filenames — the website looks for these names.

─────────────────────────────────────────────────────────
  HER MAIN PHOTO  (Hero section)
─────────────────────────────────────────────────────────
  her-photo.jpg       → Her portrait photo for the top section
                        Best size: 600 × 800 px (portrait)

─────────────────────────────────────────────────────────
  TIMELINE PHOTOS  (Our Journey section)
─────────────────────────────────────────────────────────
  photo-01.jpg        → Event 1: First Date (3 Aug 2025)
  photo-02.jpg        → Event 2: The Proposal (20 Aug 2025)
  photo-03.jpg        → Event 3: September 2025 event
  photo-04.jpg        → Event 4: October 2025 event
  photo-05.jpg        → Event 5: November 2025 event
  photo-06.jpg        → Event 6: December 2025 event
  photo-07.jpg        → Event 7: January 2026 event
  photo-08.jpg        → Event 8: February 2026 event
  photo-09.jpg        → Event 9: March 2026 event
  photo-10.jpg        → Event 10: April 2026 event
  photo-11.jpg        → (if you add more events)
  ...up to photo-25.jpg

  Best size: 800 × 450 px (landscape / 16:9 ratio)

─────────────────────────────────────────────────────────
  FRIEND PHOTOS  (Wishes section)
─────────────────────────────────────────────────────────
  friend-01.jpg       → Friend 1's photo
  friend-02.jpg       → Friend 2's photo
  friend-03.jpg       → Friend 3's photo
  friend-04.jpg       → Friend 4's photo
  friend-05.jpg       → Friend 5's photo
  ...up to friend-10.jpg

  Best size: 200 × 200 px (square, will be shown as circle)

─────────────────────────────────────────────────────────
  TIPS
─────────────────────────────────────────────────────────
  • Use .jpg for photos (smaller file size, faster loading)
  • Use .png only if the photo has transparency
  • Keep each photo under 500 KB for fast loading
  • You can compress photos for free at: squoosh.app
  • If a photo is missing, the website shows a placeholder
    box — it won't break or look broken.
